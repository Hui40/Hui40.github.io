什么是IPv4，什么是IPv6？

Hui2026-10-012026-10-01

开头

你有没有经历过这样的场景——

某天你在刷视频，刷到一条讲“网络”的内容，视频里的博主滔滔不绝：“现在的IPv6已经全面普及了”“你家宽带要是不支持IPv6，说明你家路由器太老了”“IPv4地址早就耗尽了”……

你听着听着就懵了：IPv4？IPv6？这俩是什么东西？为什么一个叫4，一个叫6？那IPv5去哪了？是被吃了吗？

于是你打开电脑，想自己查一查。结果一搜，出来的全是这种句子：

“IPv4采用32位地址长度，以点分十进制表示”
“IPv6采用128位地址长度，以冒号十六进制表示”
“IPv6解决了IPv4地址枯竭问题，并支持无状态地址自动配置”

……每个字你都认识，但连在一起，你还是不知道它在说什么。32位？128位？地址枯竭？这不是在讲网络吗？怎么跟数学课似的？

你甚至开始怀疑：我是不是太笨了？连个IP都搞不懂？

别慌。

你一点都不笨。这些问题之所以看不懂，不是因为难，而是因为没有人从最根本的地方给你讲起。那些文章是写给已经懂网络的人看的，负责“复习”，而不是负责“教学”。

所以这篇文章，慧妈打算换个讲法——不背术语、不甩概念，就从你每天上网这件事本身讲起，让你看完之后能清清楚楚地明白：

什么是IPv4？什么是IPv6？它们俩到底有什么区别？以及，为什么非得搞出个IPv6不可？

下面我们开始教学。

知识科普

一、先搞懂“IP地址”是个啥

在讲IPv4和IPv6之前，我们得先把一个更基础的概念搞明白：IP地址。

你可以把互联网想象成一个超级巨大的小区。这个小区里住了无数户人家：有你家的电脑、你爸妈的手机、你家的智能电视、还有隔壁老王家那台24小时开着的NAS（网络存储服务器）。

那么问题来了，小区里这么多户人家，快递员怎么把包裹准确地送到你家，而不是送到老王家呢？

答案很简单：每户人家都有一个门牌号。

互联网也是同理。IP地址，就是每一台联网设备在这个“互联网小区”里的门牌号。 你的电脑、你的手机、你家里的路由器、甚至你访问的那些网站的服务器，全都靠这个门牌号来互相找到对方、互相通信。

举个例子：当你在浏览器里输入网址，敲下回车的那一刻，你的电脑其实是在干这么一件事——

“我要找这个网站，它的门牌号是多少？找到之后，把我的请求寄过去。”

网站收到请求，处理好之后，再按照你留下的门牌号，把数据原路寄回给你。

这就是你每次打开一个网页，背后发生的事。你看到的“唰”一下就加载出来的页面，其实是你的电脑和远在千里之外的服务器，用门牌号互相寄了好几轮包裹的结果。

那么现在的关键问题就来了：这个门牌号，到底长什么样？

答案不止一种。目前全世界在用的门牌号规则，有两套——它们分别叫做 IPv4 和 IPv6。

接下来，我们就一个一个讲。

二、IPv4——我们用了四十多年的老门牌号

1.IPv4长什么样？

IPv4的全称是 Internet Protocol version 4，翻译过来就是“互联网协议第4版”。

它的门牌号长这样：

是不是有点眼熟？你以前可能在路由器背面、或者在电脑的网络设置里见过这种样子的数字。

这种格式叫做点分十进制，说白了就是：用四组数字，中间用小数点隔开。

那这四个数字能随便取吗？不能。每一个数字的范围都是 0 ~ 255，超过255就不合法了。所以你永远看不到 192.168.300.1 这种地址，就像你永远看不到“门牌号300号”挂在一个只有200户的小区里一样。

2.算一笔账：IPv4到底能装多少户人家？

我们在前面说，IPv4的地址是由四组数字组成的，每一组数字有256种可能（0到255，一共256个）。

那么总的门牌号数量就是：

256 × 256 × 256 × 256 = 4,294,967,296

也就是大约 43亿个。

43亿个地址，听起来是不是还挺多的？在IPv4刚诞生的那个年代（1981年），互联网上总共也就几百台电脑，全世界所有人都觉得：这辈子都用不完。

然而，四十多年过去了，情况变成了什么样呢？

现在全世界有多少人在上网？五十多亿！！！

而且注意，不是“一个人占一个地址”——你家里有电脑、有手机、有平板、有智能电视、有扫地机器人、有智能音箱、有智能门锁、有摄像头……每一样能联网的设备，都要占一个门牌号。

一家四口，可能就是十几个设备。工厂、公司、学校里的服务器，更是一台就是一个地址，机房里的服务器动辄排成几十排。

于是，43亿个地址，早就被分完了。

事实上，早在2011年，全球的IPv4地址池就已经正式宣告耗尽；到2019年，连最后一个IPv4地址也被分配出去了。

打个比方：IPv4就像一栋只有43万套房子的小区，本来以为住户也就几千人，结果四十年后涌来了几百万住户，不光房子住满了，连楼道里、楼梯间都塞满了人。房子早就不够分了。

不过你可能会疑惑：那我家的电脑手机现在不还是好好地在上网吗？也没见谁上不了网啊？

这里慧妈要给你讲一个非常关键的操作，叫做NAT。

3.救场招数：NAT（网络地址转换）

既然门牌号不够用，那就共用呗。

我们接着用小区来打比方。IPv4门牌号不够，就好比这个小区里只有一户人家的门牌号是真实有效的，比如就是 100号楼1单元101室。

那怎么办？整栋楼的人都共用这一个门牌号。

快递员送来包裹，只送到这户人家门口；然后这户人家的“管家”（也就是你家的路由器）看一眼包裹上的收件人名字，比如“给老张的”，就转手送到老张手里；是“给小李的”，就送到小李手里。

——这就是NAT，全称网络地址转换。

你家宽带从运营商那里只拿到了一个公网IP（就是那个“真实有效的门牌号”），但你家里的电脑、手机、电视，每一个都有自己独立的“内部编号”（这些内部编号通常长这样：192.168.1.xxx，注意：任何以192.168开头的IP地址都属于内网IP，只能访问处于同一局域网内的对应IP的设备，无法访问局域网之外的设备，“localhost”开头的也是同理）。

当你家的电脑要上网时，路由器会偷偷把包裹上的发件人，改成自己那个唯一的公网门牌号再发出去；等回信到了，路由器再根据记录，把回信准确地转交给当初发信的那台设备。

整个过程，你的电脑完全不知情，网站也不知道——双方都以为是直接对话。只有路由器在中间忙前忙后。

所以，现在你能上网，不是因为你的设备有独立门牌号，而是因为你家路由器在门口替全家收发快递。

NAT很聪明，但它也有明显的坏处：

  • 效率变低：每次数据都要路由器转换一遍，来回折腾，增加了延迟
  • 身份难辨：网站只知道是“你家”访问了它，不知道具体是你家哪台设备
  • 端到端连接困难：像远程桌面、P2P下载、智能家居远程控制这些需要“两台设备直接对话”的场景，被NAT挡在门口，经常连不上（如果你玩游戏时提示“NAT类型受限”，就是这个原因）
  • 配置麻烦：想让外面的设备主动连进你家，就得手动做“端口映射”，而这一步对小白来说简直是天书

一句话总结：NAT是个应急的补丁，能用，但不优雅。

三、IPv6——重开一局的新门牌号

既然IPv4挤得像春运的火车，那干脆重新设计一套门牌号系统——这就是IPv6。

IPv6的全称是 Internet Protocol version 6，也就是“互联网协议第6版”。

（顺便回答开头那个问题：IPv5去哪了？ IPv5确实存在过，但它是一个实验性的协议，主要是为音视频流设计的，从来没有大规模部署过，后来就被放弃了。所以我们的门牌号直接从第4版跳到了第6版，中间的第5版只活在历史文档里。）

1.IPv6长什么样？

它的门牌号长这样：

第一次看到是不是有点头皮发麻？八组，中间用冒号隔开，每组还是十六进制的（也就是除了 0-9，还有 a-f）。

这种格式叫做冒号十六进制。虽然看起来比IPv4长得多、怪得多，但请你先别急着害怕，我们一会儿算完账你就明白了。

2.算一笔账：IPv6到底能装多少户人家？

我们还是用刚才的方法算一遍。

IPv6由八组数字组成，每一组是十六进制的，也就是16种可能（0-9加上a-f），所以每一组是 ( 16^4 = 65536 ) 种可能。

那么总数量就是：

65536 的 8 次方 = 2 的 128 次方 ≈ 3.4 × 10³⁸

这个数字有多大呢？340,282,366,920,938,463,463,374,607,431,768,211,456 个。

这么说吧：

  • 地球上的每一粒沙子，都能分到一个IPv6地址，而且还绰绰有余
  • 就算你把整个地球表面每一平方毫米都填满一台联网设备，地址也远远用不完
  • 有人认真算过，如果按每秒分配10亿个地址的速度，把IPv6地址发完需要的时间比宇宙的年龄还长

对比一下：

IPv4 IPv6
地址总数量 约43亿个 约3.4×10³⁸个
够不够用 2011年就耗尽了 宇宙灭亡都用不完

这就是IPv6带来的最大改变：门牌号多到根本不需要共用。

3.IPv6带来的好处

门牌号够多了，很多以前靠“打补丁”解决的问题，就自然消失了。IPv6带来的好处主要有这几个：

  • 每个设备都有独立公网地址：不用再挤一个门牌号了，你家每台设备都能拥有自己的“真实门牌号”，NAT可以彻底退休
  • 端到端直连，速度更快：两台设备可以直接对话，不用路由器在中间来回转手。远程访问家里的电脑、NAS、摄像头，变得非常简单直接
  • 自动配置，插上就能用：IPv6支持无状态地址自动配置（SLAAC），设备接入网络后能自己“领到”一个地址，不用像IPv4那样又是DHCP又是手动设置，插上网线就能上网
  • 安全性更好：IPv6在设计阶段就把IPSec加密作为标配，虽然不是强制使用，但底子要比IPv4的好
  • 不用再搞端口映射：想在外部访问家里的设备，不再需要去路由器里配置那堆让人头秃的“端口映射”规则

不过慧妈也要说句公道话：IPv6也不是完美无缺的。 因为地址太长太复杂，纯靠人脑去记几乎不可能（IPv4的 192.168.1.1 你还能背下来，IPv6的地址你试试？），而且很多老旧设备、老旧网站到现在还不支持它，所以在未来很长一段时间里，IPv4和IPv6会同时存在，这就是所谓的“双栈”模式。

四、两者到底有什么区别？

讲了这么多，我们把IPv4和IPv6的差别整理成一张表，看起来更清楚：

对比项 IPv4 IPv6
全称 Internet Protocol version 4 Internet Protocol version 6
地址长度 32位 128位
表示方式 点分十进制，如 192.168.1.1 冒号十六进制，如 2408:8260:...
地址总数 约43亿个 约3.4×10³⁸个
地址够不够 2011年就耗尽了 根本用不完
是否需要NAT 需要，全靠NAT续命 不需要，每台设备可独立公网
地址配置 手动配置或DHCP 支持自动配置（SLAAC）
端到端连接 受NAT阻隔，困难 直连通畅
安全性 后期打补丁（IPSec可选） 设计之初就内置IPSec
普及程度 全面普及，但仍不够用 正在普及，与IPv4共存

聪明的你可能发现了，IPv6本质上是把IPv4当年设计时留下的所有遗憾，全部重新做了一遍。

当年设计IPv4的人，没想到互联网会普及到几十亿人，也没想到家里的冰箱、灯泡、门锁都要联网。所以他们只留了43亿个地址，觉得够用一辈子了。

而IPv6的设计者，吸取了教训，直接一步到位——给宇宙里每一粒沙子都留了个位置。

五、手把手：查看你自己电脑的IP地址

看到了吗？你的电脑同时拥有两个地址。

那个 192.168.1.xxx 就是你的IPv4地址，它是你家路由器分配的内部编号；而那个一长串带冒号的，就是你的IPv6地址，它通常是由运营商分配给你的公网门牌号。

方法二：用鼠标查看（更直观）

  • 点击桌面任务栏右下角的网络图标，点击网络和 Internet 设置

（fe80:: 开头的这种地址叫做链路本地地址，它只在你自己家局域网内部有效，出了家门就不认了，所以它不能用来上网，看到它不代表你的IPv6已经启用。）

六、几个你一定会好奇的问题

问：IPv6都出来了，那IPv4是不是要淘汰了？我家电脑会不会上不了网？

答：放心，不会。 IPv4和IPv6是两套完全平行的系统，它们不是“新版本取代旧版本”的关系，而是“同时并存、各干各的”。现在绝大多数设备和网站都支持“双栈”，也就是IPv4和IPv6两手都抓、两边都能聊。所以你家现在的IPv4网络，未来很多年都会继续正常工作，不用担心电脑突然上不了网。

问：为什么我的地址有时候是 192.168.x.x，有时候是 10.x.x.x？为什么都是“内网地址”？

答：这些开头的地址，是国际标准里专门留给局域网内部使用的“私有地址”，也就是说，它们不能直接在公网上使用。类似的还有 172.16.x.x 到 172.31.x.x。你家的电脑、手机拿到的都是这种地址，真正的公网门牌号在你家路由器那里。这就是前面说的NAT在起作用。

问：怎么判断自己家有没有用上IPv6？

答：最简单的办法就是按前面说的方法看一下。如果你在 ipconfig 里看到了一长串带冒号、不以 fe80 开头的地址，那就是用上了。或者你可以访问一些专门检测IPv6的网站，如果显示“IPv6 已接入”，那就是已经用上了。

问：既然IPv6这么好，为什么到现在还没普及完？

答：因为换门牌号不是换个号码那么简单。整个互联网上跑着无数的设备：老电脑、老路由器、老网站、老软件……它们全都写死了只认IPv4，要让它们全部升级，工作量极其庞大，而且要花很多钱。所以这注定是一个慢慢过渡的过程，可能要再花十几二十年。另外，因为IPv6的访问中间没有NAT，所以设备与设备之间通过IPv6传输文件在速度和延迟上都会强上不少，所以当你有公网IPv6地址时，访问的网站如果也支持IPv6连接，那么会优先通过IPv6进行连接和传输数据，否则以IPv4传输数据。

问：那IPv5呢？它到底去哪了？

答：我们前面已经说过啦——IPv5是一个只在实验室里活过的实验性协议，专门为音视频流设计的，从没大规模使用过，后来就被放弃了。所以门牌号从第4版直接跳到了第6版，第5版只留在历史文档里。你不是数错了，是真的没有IPv5。

结语

好了，以上便是本期教学的所有内容了。

我们回过头来看，其实这篇文章真正讲透的，只有一件事：

IPv4是那个用了四十多年、只有43亿个门牌号、挤到要靠NAT续命的老地址系统；而IPv6是重新设计、拥有3.4×10³⁸个门牌号、能让每台设备都拥有独立身份的新地址系统。

一栋楼挤满了人，于是我们盖了一栋新的楼——楼里空得能装下整个地球的沙子。

看到这里，想必你已经明白了，IP地址不是什么高深莫测的东西，它就是网络世界的门牌号；而IPv4和IPv6的区别，说到底就是 “够不够用” 四个字。以后再看到有人讨论IPv6扩容、地址枯竭，你就能听懂他在说什么了。
