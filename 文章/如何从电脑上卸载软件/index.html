如何从电脑上卸载软件

Hui2026-09-012026-09-01

开头

“明明空间不够了，为什么我删了几个大软件，C盘还是飘红？”
“为什么我把桌面的图标删了，开机它还是自己弹出来？”
“为什么我把整个文件夹拖进回收站了，想重装却总是失败？”

如果你在使用电脑的时候，也曾出现过以上的问题，那么请先深呼吸，放轻松——电脑没坏，你也没手残，你只是在卸载软件的时候用错了方法。

很多小白朋友对“卸载软件”这件事有一个根深蒂固的误解：把“删除快捷方式”等同于“卸载程序”。

这个误解的代价是巨大的。

  • 当你只删快捷方式时，软件本体依然在硬盘里安然无恙，占着你的内存，甚至还在后台偷偷自启，拖慢开机速度。

  • 当你暴力删除文件夹时，相当于把一棵树的树干砍了，但树根（注册表和驱动）还深深扎在 Windows 的系统土壤里。这不仅会让系统变“脏”，更会在你下次安装同款软件时，因为旧根未除而导致安装直接报错。

别看“卸载”两个字说起来轻巧，这背后其实藏着 Windows 系统最基础、但最容易被忽略的文件管理逻辑。

本期文章将教大家如何用正确的方式删除、卸载掉电脑里那些你不想要的软件，也教大家如何将软件删得更干净。

教学内容

卸载电脑软件的方式有很多，但绝对不是像手机一样将软件图标拖进回收站这么简单的，所以本期就教大家四种方式卸载电脑上的软件，前两种是windows自带的卸载程序，能有效地卸载软件，但卸的并不干净，后两种是第三方卸载软件的应用程序，可以在最大程度上删除掉软件在电脑上留下的所有痕迹，所以我推荐大家卸载软件的时候使用后两种方法，这样较为简单，且更有效。

方法一

  • 单击键盘上的win键或者点击任务栏中的windows图标，点击设置

  • 找到并点击“应用”一栏

  • 点击“安装的应用”

  • 找到你想卸载的软件，这里我们以汽水音乐为例，点击该应用所在的一栏的最右边的三个点，然后点击卸载

  • 继续点击卸载

  • 然后你便进入了该软件的卸载程序，这里我们点击卸载

  • 卸载完成了，我们点击完成，一次简单的卸载软件操作便执行成功了

方法二

该方法需要用到控制面板，如果你不知道控制面板怎么打开或者桌面上没有控制面板的图标，请展开以下内容查看如何把控制面板放到桌面👇👇👇

点击展开查看详细步骤

  • 用跟刚才一样的方法打开电脑的设置界面，找到并点击“个性化”一栏

  • 找到并点击“主题”一栏

  • 点击桌面图标设置

  • 在打开的界面中把控制面板的选项勾上，随后点击确定并返回，你的桌面上就有控制面板图标了

  • 在桌面上找到并双击点开控制面板

  • 在右上角将查看方式改成类别，然后在程序类别点击卸载程序

  • 找到你要卸载的程序，右键并点击卸载，或者直接双击它

  • 这时我们发现又弹出了软件的卸载程序，之后用与之前相同的操作步骤卸载该软件即可

方法三

  • 点此链接👉Geek Uninstaller，进入知名第三方卸载软件Geek Uninstaller的下载界面，然后点击带ZIP标识的按钮（当然7Z标识的按钮也行，这里以前者为例）

  • 文件下载下来之后，鼠标单击选择该文件，然后点击鼠标右键，选择你常用的压缩软件对其进行解压，这里以我常用的Bandizip为例，具体步骤如下
    注：如果你的电脑上没装压缩软件或者说压缩软件是需要收费的盗版软件，请点此链接下载Bandizip压缩软件👉Bandizip官网链接（下载免费版即可）
    若不知道如何下载软件，请跳转到此链接跟慧妈学习如何下载安装软件👉如何下载软件

  • 解压之后，鼠标单击选择刚刚进行解压的压缩包，按住键盘上的Ctrl + D，将此文件删除，然后鼠标单击选择你刚刚解压下来的文件，及geek.exe，按住键盘上的Ctrl + X，剪切其文件，然后选择并打开你一个用于安装软件的文件夹，文件夹名字最好为英文，按住键盘上的Ctrl + V，将文件粘贴到该文件夹中

  • 如果你需要更快捷地打开此文件的话，可以建立该文件的快捷方式，将快捷方式保存到桌面，这样就可以在桌面打开此卸载程序了。选中该文件后点击鼠标右键，然后点击显示更多选项

  • 点击创建快捷方式

  • 然后用与刚才类似的方式将文件夹中新出现的快捷方式剪切并粘贴到桌面上去，随后在桌面上像平时打开其他软件一样双击此图标打开该软件

  • 点击“是”

  • 出现软件列表界面之后，选择你要进行卸载的软件，右键，随后点击卸载

  • 此时软件的卸载程序出现，用相同的方式操作卸载该软件

  • 执行相应操作走完了软件自身卸载程序的卸载流程之后，此时第三方卸载程序会扫描该软件的残留文件及其注册表，扫描完毕之后，我们点击完成，该软件就算是被删干净了

  • 那么问题来了，有的时候我们想卸载的是从微软商店下载的软件，或者是windows系统本身自带的软件，在这个软件列表上看不到，怎么办呢？不要慌，这时，我们点击上方的查看按钮，然后点击“Microsoft Store Apps”即可，这样就可以显示这些原来列表里看不到的软件了，那么怎么切回原来的状态呢？再次点击查看，然后点击“Desktop Apps”即可

方法四

  • 点击此链接👉Hibit Uninstaller，跳转至软件Hibit Uninstaller的官网下载界面，然后点击Installable version按钮

  • 软件的安装程序下载好后，打开此安装程序所在的下载文件夹，然后双击此安装程序

  • 点击“是”

  • 随后按正常的流程走完安装程序即可

  • 软件安装完毕之后，在桌面上找到此软件的快捷方式，然后双击此软件

  • 打开此软件之后，出现了已安装的软件的列表，随后在此列表中找到你想卸载的软件，单击选中，然后单击鼠标右键，随后点击卸载

  • 依旧按正常的卸载流程走完该软件自带的卸载程序

  • 软件卸载完成之后，会出现像这样的准备就绪的界面，点击高级扫描，然后点击扫描

  • 等待稍许，扫描完毕之后，将左下角的“清理后打开报告文件”和“创建备份”都保持为取消勾选状态，随后点击右下角的完成

  • 好的，这样一个软件就最大程度上地被删除干净了，还是同样的问题，如何删除微软商店安装的软件以及windows自带的软件？这时我们点击右上角的工具，然后点击Windows应用商店应用管理器，即可显示windows应用商店的软件，然后用相同的方式删除即可

注意事项

在用到后面两种方法提供的两种软件卸载程序的时候，请注意，不要随便删除windows自带的一些软件，除非你清楚地知道自己在干什么，而自己在微软商店上下载的软件，卸载了就卸载了，之后还能重新装回去，这点要区分清楚。

同时，Hibit Uninstaller是一款强大的、多功能的卸载软件，它除了把软件卸载干净之外，还可以为你提供清理电脑上的垃圾文件、空文件夹、注册表等等多种功能的服务，这些都在软件打开的界面的工具这一栏可以看到，但是，除非你对删除文件已经有了一定程度上的熟练度，并且清楚地知道自己在做什么，否则不要随便删除注册表，一旦删除错了，将对你的windows系统造成不可逆的损伤，这点要万分小心。

所以，慧妈非常推荐小白使用Hibit Uninstaller卸载软件，但也十分不推荐小白使用该软件的工具里的一些除卸载软件之外的其他的自己不明确的扩展功能，这点需谨慎使用，还请注意！
