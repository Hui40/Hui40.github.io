新买的1TB固态，装电脑上显示只有900多GB，是商家在坑我吗？

Hui2026-09-152026-09-15

开头

你是一个电脑小白。

这几天，你终于狠下心来，花了大价钱钱买了一块1TB的固态硬盘。想着总算能给快塞满的C盘松松绑，把那几个舍不得删的游戏装回来，还能顺手存一堆电影和照片。

硬盘到了。你小心翼翼地拆开电脑，装上硬盘，开机——一切顺利。可是当你打开”此电脑”，看到那个新出现的盘符时，你愣住了。

容量那一栏写着：931GB。

不对啊。你买的明明写着 1TB。1TB 不就是 1024GB 吗？就算按 1000 算，那也该有 1000GB 才对。931GB……那少的将近 70 个 G 去哪儿了？

你把包装盒翻出来又看了一遍，大字写着”1TB”，没错。你打开订单页面，商品标题也写着”1TB”，没错。你甚至开始回想——是不是买到二手盘了？是不是翻新盘、缩水盘？是不是商家偷偷在坑我？

先别急，深呼吸一下。

我可以很确定地告诉你：你没有被坑，你的硬盘也一点毛病都没有。那”消失”的 69GB，从始至终都好好地躺在你的硬盘里，一个字节都没少。

真正的原因说出来可能有点意外——不是硬盘少了容量，而是”1TB”这三个字，在硬盘厂商和 Windows 嘴里，根本是两个意思。

知识科普

在开始之前，先给你吃个定心丸：你的硬盘一点问题都没有，一块钱的容量都没少给你。

那么问题来了，那 “消失”的 69GB（或者更多）到底去哪了？ 答案很简单——它从来没有消失过，只是”GB“这个单位，被用成了两个意思。

打个比方。你去买布料，店家说”一米布”，你拿回家用自己那把尺子一量，只有 0.91 米。你气得想退货——结果发现，店家的一米是 100 厘米，你量的时候用的是另一种”米”，它等于 109.7 厘米。

尺子没错，布也没少，只是两把尺子不一样长。硬盘和 Windows 之间，就是这个情况。

1000和1024

在硬盘制造商的换算标准中：
1KB = 1000 字节，1MB = 1000KB，1GB = 1000MB，1TB = 1000GB。这是国际单位制（SI）的规定，跟我们平时数数一样，是十进制的。

而在windows系统中，也就是你现在用的电脑中，换算标准是这样的：
1KB = 1024 字节，1MB = 1024KB，1GB = 1024MB，1TB = 1024GB。因为计算机底层是二进制，1024 正好是 2 的 10 次方，用起来”整齐”。

这时我们将两组数据摆在一起看：

硬盘厂商 Windows
1KB 1000字节 1024字节
1MB 1000KB 1024KB
1GB 1000MB 1024MB
1TB 1000GB 1024GB

看出问题在哪了吗？每一步都差一点点，但”字节→KB→MB→GB→TB”要连乘四次，误差就被放大了 4 次。

算一笔账

假设一块 1TB 硬盘，厂商装了 1,000,000,000,000 字节（一后面 12 个 0），这是厂家按 1000 进制算出来的 1TB。

现在 Windows 拿着自己的尺子来量：

  • 除以 1024 → 976,562,500 KB
  • 再除以 1024 → 953,674 MB
  • 再除以 1024 → 931.32 GB

于是”此电脑”里就有了那个让人心梗的数字：931GB。此时你恍然大悟——天哪，原来自己电脑上的931GB是这样来的啊。

同理，我们继续往下推：

你买的 电脑显示 看起来“少”了
256GB 238GB 18GB
512GB 476GB 36GB
1TB 931GB 69GB
2TB 1862GB 138GB

发现没，硬盘的存储空间越大，因为换算规则差异而“损失”的硬盘存储空间越多。及盘越小，数字差得越小；盘越大，数字差得越大！ 所以16GB的U盘只“少”了1GB左右，而1TB的硬盘却“少”了69GB——但实际上它们的存储空间从来都没有少过。

你可能遇到的一件更奇怪的事

到这儿还没完。有些朋友会发现，自己的 1TB 硬盘显示的居然是 954GB，而不是 931GB。

这不是坏盘，也不是”赚到了”，原因藏在一个更细的地方。

我们前面假设的是”厂商给了正好 1,000,000,000,000 字节”。但实际生产中，硬盘里真正能用的字节数并不固定是个整十进制的数。你可以在硬盘属性的”容量”那一栏，看到一长串精确到个位的数字。比如：

  • 1,000,204,886,016 字节 → 除以 1024³ = 931.51GB
  • 1,024,209,543,168 字节 → 除以 1024³ = 953.87GB

第二个数字你多看一眼——它正好是 1024 的整数倍，也正好是 512 的整数倍。也就是说，这块盘厂商实际给的空间，相当于”1024GB”那么多，比标称的 1TB 还多了 24GB 左右。

所以结论是：厂商印在包装上的容量，是一个”不少于”的承诺，不是”正好等于”。 同一款标 1TB 的盘，不同批次、不同主控，实际字节数可能不一样，Windows 里看到的数字自然也可能不一样。

这就解释了为什么网上有人说”我的 1TB 显示 934GB”，另一个人跳出来说”胡说，我的是 954GB”——两个人都是对的，他们只是两块不同的盘。

怎么确认自己没被坑？

第一步，看字节数（最重要）

打开”此电脑” → 找到你的硬盘 → 右键 → 属性。看”容量“那一栏。

如果你看到的是 1,000,xxx,xxx,xxx 或 1,024,xxx,xxx,xxx 这种一开头的 13 位数字——恭喜，这就是实打实的 1TB，一个字节都没少。

第二步，理解为什么”两个界面两个数字”

很多人会在”磁盘管理”里看到 953869 MB 这样的数字，然后和”此电脑”里的 931GB 对不上，彻底懵了（我自己就被这个数字绕进去过）。

其实一点都不矛盾——因为单位不同。MB 除以 1024 才是 GB：

同一个东西，一把尺子量出两个读数，只是因为你换了单位看而已。看数字之前，先看单位——这句话能帮你破解全网 90% 的”容量玄学”。

什么情况才是真的被坑了？

讲到这里，你就得注意了。下面这些情况，才是真有问题：

  • 磁盘管理里显示的容量，跟标称差出一倍以上（比如标 1TB 只有 460GB 左右）——可能是假盘、扩容盘
  • 拷贝文件时，一旦超过某个容量就报错、文件损坏、或者拷进去的东西读不出来
  • 用工具测出来的实际写入量，明显小于显示的容量

而下面这些，都是正常的，不用慌：

  • 显示 931GB 或 953GB，即使格式化后还少了几个 GB（文件系统本身要占一点地方）
  • “此电脑”和”磁盘管理”里数字不一样
  • U 盘、内存卡、手机存储，都”少”了一点（这个凭自己主观判断，差不多估一估就行了）

总结

看到此处，想必你已经明白了：你的硬盘并没有骗你。硬盘厂商卖给你的，是 1000 进制下的容量；Windows 量给你看的，是 1024 进制下的读数。一笔账，两把尺子，从头到尾都是同一块硬盘。你花的每一分钱，都变成了实实在在的存储空间——只不过其中一部分，是藏在”单位”这两个字里的。
