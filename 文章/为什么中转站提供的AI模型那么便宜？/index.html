为什么中转站提供的AI模型那么便宜？

Hui2026-11-092026-11-09

开头

事情是这样的。

你手上有个老项目，几百个文件，几年前写的，里面到处在用一套早就废弃的接口。真要一个一个改，能改到明年。

于是你想到了 Agent——就是上一篇《Agent 是怎么通过 Token 帮你干活的？》里讲的那个，会自己读文件、自己改、自己跑程序的家伙。你把整个文件夹丢进去，打了一句话：

把项目里所有用到旧接口的地方找出来，改成新写法，改完跑一遍测试。

这种活儿，聊天框干不了。它得读代码、得动手、得看报错。

几百个文件，连代码带注释，大概 120 万 token。

你去官网看了一眼价目表：

掏出计算器按了一下：

按七块一换，三十七块钱。

干一次三十七块，说实话不便宜，但也不是不能接受——毕竟它替你干了三天的活。

然后你在一个群里看到有人甩了个链接。同一个模型，同一个版本，标价写着：

官方价的一折。

你点进去。注册只要手机号，充值支持支付宝，最低十块起。你充了十块，把同一段代码、同一句话，原封不动地贴进去。

它动了。

文件列表一个个冒出来，代码一行行往下长，终端里滚过测试输出，最后停在一行绿字上：

跑完了，一个报错都没有。账单也出来了：

$0.52。

三块七。

你盯着这两个数字看了很久：5.20 和 0.52。

官方 中转站
模型 同一个 同一个
提示词 同一段 同一段
结果 142 passed 142 passed
账单 $5.20 $0.52

同样的模型，同样的活儿，同样的结果，差了一个零。

这时候，正常人的脑子里会同时冒出三个问题：

它凭什么这么便宜？

官方的价格里，到底有多少是成本，多少是它愿意让的利？

我花三块七买到的，和人家花三十七块买到的，是同一个东西吗？

这三个问题，就是这篇文章要回答的全部内容。

而且我先把最难听的那句话放在前头：

这三个问题的答案，不是同一个。

因为”便宜”这件事，在 AI 中转站这个行当里，至少有四条完全不同的路，能走到同一个价签上。

有的路是本事，有的路是套利，有的路是缩水，还有一条，是犯罪。

它们在你的账单上，长得一模一样。

本篇是AI知识系列科普的第三篇。

这一篇接着往下走：当 token 变成一张账单，账单上的数字是谁定的、能压到多低、压下去的那部分又去哪儿了。

前两篇里有两个概念，这篇会反复用到：token（块），以及输入和输出分开计价。

如果这两个词你还有点陌生，建议先回去翻一下第一篇——我在那里面把”块”这件事从头拆过一遍，拆得比这篇细。不翻也能读，就是会稍微卡一下。

看完之后，下面这几件事你应该能跟别人讲明白：

  1. 中转站到底在卖什么，你的钱经过了谁的手
  2. 官方的价格里，哪些是硬成本，哪些是可以让的
  3. “一折”这个数字，有哪几种凑法，各自能撑多久
  4. 便宜的代价具体落在哪儿——不是虚的”有风险”，是能说出名字的那一种
  5. 拿到一个陌生的站，怎么用半小时判断它靠不靠谱

那我们就从最实在的地方开始：钱到底是怎么流的。

知识科普

一、钱是怎么流的：中转站到底在卖什么

1. 一条请求，走过了谁

你在那种站上充值、拿到一个 sk- 开头的 key，然后把它填进某个软件里——这事就算成了。

但这一条请求，中途其实拐了两个弯：

关键在 ② 和 ③ 这两步。

你和官方之间，隔了一个”买家”。

这个买家从官方进货，再转手卖给你。它进货花的是美元、走的是官方账单；它卖给你收的是人民币、走的是它自己定的价目表。

所以它的利润，就是一句话：

利润 ＝ 你的付款 − 它的进货成本

这句话看着像废话，但它是全文的钥匙。因为接下来所有的疑问，最后都会绕回这一行：

当它卖得比进货价还便宜的时候，那个差额，是谁补的？

（顺带说一句，这东西的叫法很杂：中转站、API 中转、API 代理、镜像站、合租站，说的基本是同一类东西。）

2. 它最早卖的不是”便宜”，是”省事”

很多人以为中转站能活下来，是因为便宜。

不完全是。

它最早卖的是”门槛”。

官方 API 对国内普通用户来说，至少有四道坎：

坎 具体是什么
支付 要 Visa / Mastercard，很多人手里没有
网络 有些地区直连不稳，得自己想办法
资质 有的平台要企业主体、要对公账户
账号 一家一个号，OpenAI、Claude、Gemini 各注册一遍，各绑一张卡

中转站把这四道坎，一次性搬走了：一个手机号注册，支付宝充值，一个 key 通吃好几家模型。

对小团队和个人开发者来说，光这一条就值钱——省下的不是钱，是折腾的时间。

这也是为什么它敢加价卖。 你去看看那些不搞价格战的站，标价经常是官方的 1.2 倍、1.5 倍，照样有人买，还买得挺稳。

“方便”本身就是一个可以定价的商品。 便宜只是它后来用来抢客户的手段。

这两件事得分清楚：“它为什么存在”和”它为什么便宜”，是两个问题。 第一个问题的答案是方便，第二个问题的答案，才是这篇文章要拆的。

3. 一个特别容易被忽略的区别

官方 API 的账单是透明的。一次调用输入多少 token、输出多少 token、单价多少、合计多少，一条一条列着，你能自己核对。

中转站不是这样。你充十块钱，它给你一个”额度”，你看着那个数字往下掉，但它是怎么掉的、按什么价掉的，你不一定看得见。

这个区别听起来很小，其实很大：

官方卖的是”计量之后的用量”，中转站卖的是”它自己定的额度”。

一旦额度是它自己定的，它就有三种活法：

  1. 按官方价算，赚个汇率和手续费——能活，但不刺激
  2. 按自己的价目表算，卖得比官方贵——活得很滋润，靠的是方便
  3. 卖得比官方还便宜——这就是我们要拆的那一种

第三种活法，账面上是亏的。凡是账面亏的生意，钱一定是从别的地方来的。 要么就是成本极低，要么就是陷阱——当一个中转站的模型过于便宜，甚至免费时，那么它贩卖的商品不一定是模型，很有可能是你，也就是你的私人信息！

二、第一层：批发——能省，但天花板比你想的低

1. 大客户价，没有想象中那么狠

任何做 API 生意的公司，量大了都能谈价。签年框、预付、承诺用量，拿到 5% 到 20% 的折扣，是常规操作。

这一层是真的。但它也就这样了。

因为推理这个东西，成本是硬的。 一张卡跑一次推理，电费、折旧、带宽、机房，一分不少。你买一万次和买一亿次，单次的边际成本降不了太多。

所以官方给的量大折扣，通常是个位数到两成。不会更多，也不该更多。

💡 这就像：你去批发市场买苹果，一次买十箱，老板给你抹个零、便宜两成，很正常。但他不可能按”苹果的种植成本”卖给你——那样他自己就赔了。

2. 缓存：把”重复的部分”打成骨折

这个折扣，比刚才那个量大折扣狠得多。

原理是：如果两次请求的前面一大段内容一模一样，官方就不用重新算一遍，直接把上次算过的东西拿出来用。 也就是我们所说的“缓存命中”。

省了算力，价格自然也就砍下来。以 Claude 为例，命中缓存的那部分输入，价格是原价的 10%。DeepSeek 更狠，缓存命中的输入是 2%——1 块钱和 2 分钱的差别。

3. 算一算：光靠折扣，能压到哪一步

回到开头那笔账：120 万输入，2 万输出，官方 $5.20。

现在只把缓存这一刀加上去。注意，缓存砍的只有输入，砍不到输出：

走法 有效输入单价 输出单价 合计 相当于官方
官方标价 $4 $20 $5.20 100%
一半输入命中缓存 $2.2 $20 $3.04 58%
全部输入命中缓存 $0.4 $20 $0.88 17%

最后一行是极端假设：120 万输入全部命中缓存，一个 token 都没漏。

现实里不可能。你每次新问的东西、新贴的代码、新改的那几行，对缓存来说都是第一次见。

而且你再看输出的那一列——它从头到尾都是 $20，一分钱没少。 缓存再猛，也只能砍输入那一半。

这就是为什么光靠折扣，压不出一个”一折”来。

（前面那个量大折扣也能叠上去，但省下的只是几个点，改变不了这个结论。各家能不能叠、怎么叠，以官方文档为准，这张表是给你看结构的，不是报价单。）

4. 但这一层，解释不了大多数情况

问题就在这儿：上面这几个折扣，你自己也能拿到。

你有官方账号，你也能谈个量大折扣，你也能命中缓存。那凭什么它做个中间商，还能再便宜一截？

而且还有两个反方向的证据。

第一，官方有时候不但不打折，还加价。

比如高峰时段。工作日白天，大家一窝蜂上来用，算力不够，官方就涨价——DeepSeek 的规矩是工作日 9 点到 12 点、下午 2 点到 6 点，价格翻倍。

中转站躲得掉吗？躲不掉。

因为它的用户也是白天在用。 没人会因为你是个中转站，就改到半夜来提问。

所以”错峰用电”这套逻辑，在 API 转售这行根本不成立。你在高峰收到的请求，就得按高峰的价买进来。想把这个成本降下去，只有一个办法：让用户等——可用户不等。

第二，中间是有损耗的。

多一层服务器转发、多一层日志、多一层计费、多一层客服。这些全是成本，一样都省不掉。

所以批发这一层，能解释的差价是有上限的。

省来省去，一半上下。 再往下压，就必须动别的东西了。

三、第二层：技术省钱——省的已经不是单价，是你拿到的东西

批发是”买得便宜”，这一层是”用得少”。

同一份货，它想办法让你少用一点，把省下的那部分装进自己口袋。

这一层有四个常见手段，一个比一个不体面。

1. 共享缓存：它确实有一个你没有的优势

前面说，缓存要”前面一模一样”。个人用户很难命中，因为每个人的对话都不一样。

但中转站不一样。

想一个典型的 AI 写作站：几千个用户，用的是同一个产品，产品发给每个人的系统提示词是同一份——“你是一个专业的中文写作助手，以下是我们的风格规范、素材库、禁用词表……”，可能两万字。

这两万字，每个用户的每次请求里都带着。对官方来说，这是同一段前缀。

于是它的缓存命中率高得吓人。你花 $4 买的那两万字，它花 $0.4。

这是它真正比你强的地方，而且是合法的、正当的、官方乐见的。 你一个人做不到，因为它需要”很多人在用同一段前缀”这个前提。

小知识：这也是为什么很多 AI 产品的系统提示词特别长。一方面是为了效果，另一方面——长提示词只要被缓存住，成本几乎可以忽略。这两件事不冲突，但确实同时成立。

2. 上下文裁剪：把”记不住”包装成”够用了”

你聊了三十轮，它突然开始忘事，前面说过的话它不认了。

你以为是模型不行。

有可能不是。有可能是站点在半路把前面的对话剪掉了。

官方的上下文窗口是 20 万 token，它只给你传 3 万，剩下的它自己删了。省下来的输入 token，全是利润。

（”上下文窗口”就是模型一次能”记住”多少内容，第一篇里用”白板”打过这个比方。忘了的话，回去看一眼就明白了。）

你感觉到的”记忆力变差”，其实是被剪过一刀。

3. 模型降级：你点的菜，不一定是端上来的菜

这个最常见，也最难查。

你选的是”最强的那个模型”，请求到了它的服务器，它看一眼：这问题不难，用小模型答就行。于是它偷偷换了。

你看到的是同一个名字，吃到的是另一盘菜。

更麻烦的是随机分配：同一个价位背后挂了好几个不同的模型，你这次运气好碰到强的，下次碰到弱的。

所以很多人才会觉得”这个站时好时坏”——不是网络问题，是它今天给你上的是哪一盘。

4. 号池：几十个人共用一把钥匙

官方账号有并发限制，有速率限制。一个号扛不住几十个人同时用。

所以站点养一堆号，把请求分散到不同的号上。

这就是”池子”。

对你来说，体验是这样的：平时挺快，一到晚上就卡；偶尔蹦一个 429；偶尔回答到一半断了。

这些都不是 bug，是池子不够大。

这一层的特点，一句话就能说完：

省下来的每一分钱，都是从你拿到的”质量”里扣的。

你付得少，你也确实少拿到了东西。只是它没告诉你，少在哪儿。

四、第三层：货源——骨折价的真正来源

到这儿，价格已经被压到官方的一半，运气好的场景能到一折。

但市面上还有更低的。九块九包月、一分钱一百次、注册就送五美元。

这些价格，靠批发和技术都凑不出来。它们来自”货源”。

先说一句前提，不然下面容易看歪：

几乎所有大模型厂商的服务条款里，都写着账号和 API key 不得转售、不得共享。

所以”中转站”这门生意，从第一天起就站在条款的边上。区别只在于——有的站在边上，有的已经掉下去了。

1. 免费额度套利：养号

几乎所有大模型厂商都有拉新预算：新用户注册，送五美元、送十八美元、送一个月会员。

这本来是一笔正常的市场费用。

但如果有人批量注册呢？

养一个号要什么？一个邮箱、一个手机号（或者接码平台）、一个干净的 IP、过一次人机验证。

成本算下来，几毛钱到几块钱。换来的，是五美元到十八美元的额度。

这是一笔套利。 它的利润不来自技术进步，来自两个数字之间的差：官方愿意为拉新付多少钱，和伪造一个号要花多少钱。

所以这类站点有个共同特征：

它今天打不开，明天又开了。

不是跑路，是那批号被封了，正在换新的一批。

💡 这就像：超市开业送鸡蛋，一人一份。有人雇了一队大爷大妈，一人领一份，再拉去菜市场卖。鸡蛋是真的，便宜也是真的，就是不知道明天还有没有。

2. 网页版侧门：把包月拆成 API 卖

这一条，是”九块九包月无限用”最大的来源。

它靠的是一个很多人不知道的事实：

网页版的会员，是包月的，不按 token 收钱。

ChatGPT Plus 二十美元一个月，Claude Pro 二十美元一个月。你一个月问一万次，还是问十万次，都是这个价。

从生意的角度看，这意味着什么？

意味着对官方来说，你多用一次，它多花一点电费，但不会再收你一分钱。 边际成本趋近于零。

于是有人干了一件事：写一套程序，把网页版包起来，对外提供 API 接口。(我们常把这种行为叫作“反代”)

你按 token 付钱给它，它拿你的问题去网页上问，再把回答抓回来给你。

它卖给你的是”会员价”，收你的是”API 价”。中间的差价，全归它。

那为什么还要养池子？

因为一个会员号是有限速的。

网页版对普通用户有频率限制：一分钟能问几次、一天能问多少、一次能贴多长的文档。一个人用，感觉不到；几十个人一起用，立刻就撞墙。

所以它必须养一池子号，把请求摊开。

一个号一分钟扛三次，十个号就能扛三十次。

这里有个很容易搞混的地方，得说清楚：

池子的作用不是”让成本变低”，是”把限速这个天花板抬高”。

真正的成本降低，发生在更前面一步——包月是一口价，拆给多少人，单次成本就被摊到多薄。 拆给五十个人，一次对话的成本就是原来的五十分之一（还没算上它自己抽的那一层）。

这才是它敢卖九块九的根本原因。

但它卖的东西，是残缺的。

官方 API 有的 网页版侧门给的
20 万 token 上下文 经常只有几万，超了直接报错
图片、PDF、文件上传 基本没有，最多贴个截图
工具调用（function calling） 极不稳定，很多站干脆不支持
并发几十上百 一个号就几个，排队
稳定的结构化输出（JSON） 经常坏格式
官方 SLA 没有，明天可能就没了

所以它便宜，不只是因为它省了钱，还因为它卖给你的本来就是简配版。

你在上面聊天、写文案，感觉不出来。一旦你要接程序、要批量、要长文档，问题全出来了。

3. 更黑的几种

还有一种便宜，来路是真的不干净。这里说清楚，不是教你怎么用，是让你知道有这回事。

转卖公司额度。 有的公司一次性买了几十万美金额度，用不完，员工或者外包私下拿出来卖。货是真的，但卖方没有转售授权，随时可能被停。

泄露的 key。 别人的 key 从代码仓库、日志、聊天记录里漏出来，被人收集起来卖。这种 key 通常活不过几天。

盗刷。 用盗来的信用卡开号、充值，再把额度卖出去。这是犯罪，也是官方打击最狠的一类。这类站点的寿命，按天算。

重要提醒：这三种，你买的时候叫”便宜的 API”，出事的时候叫”来源不明的赃物”。

4. 这行的黑话，顺便给你翻译一下

你在各种站上会看到这些词，它们说的其实是”货源”：

黑话 大致意思 成本 风险
官转 官方 key 直接转发 官方价 × 折扣 中，看卖家有没有授权
AZ 走微软 Azure 上的同款模型 云厂商价，常有企业折扣 中低，接口参数略有差异
AWS 走亚马逊 Bedrock 同上 中低
逆向 把网页版包成 API（就是上面那个侧门） 会员月费 ÷ 人数 高，能力残缺、随时封
池子 一堆免费号、试用号拼起来 单号几毛 极高，随时断流
黑卡 盗刷开的号 近乎零 最高，违法

（这些词在不同站点的含义不完全一样，别当标准术语看，当”行话”看就行。）

其实看价目表，就能猜出个大概。

官方价五到八折，大概是官转或者 AZ / AWS；一到两折，多半掺了池子或者侧门；再低，基本不用猜了。

五、同样是”便宜”，其实是四种生意

到这儿，我们可以回头回答开头那个问题了。

那些低到不科学的价签，拆开看，基本是四种东西。它们在你的账单上长得一模一样，但内核完全不同：

路子 怎么做到的 能撑多久 你拿到的是不是原来那个东西
A. 折扣 ＋ 缓存 官方折扣叠起来 能长期 是，但内容得重复
B. 号池套利 吃官方的拉新预算 撑不了太久 是，但随时会断
C. 网页版侧门 包月拆开卖 勉强 不是，能力残缺
D. 盗刷黑卡 犯罪 几天 可能是，但你在帮它销赃

最上面那一种，能压到一两折——但得挑活儿，读得多、写得少的单子才行。下面三种不挑，什么活儿都敢喊一折。

A 是本事，B 是套利，C 是缩水，D 是犯罪。

四样东西，可以写成同一个数字。所以你光看价格，是分不出来的。

慧妈把这张表放在整篇文章的中间，就是想让你记住它——以后看到任何一个”低到不科学”的价格，先在脑子里过一遍：它走的是哪条路。

这也是为什么”哪家便宜用哪家”这个策略，在 API 这行特别危险。

六、便宜的另一面：你会付出什么

前面说的都是它怎么省钱。这一节说你是怎么被省的。

1. 钱：预充值，跑路就没了

中转站基本都要先充值。你充一百，用掉二十，剩下八十在它账上。

它明天关门，这八十就是它最后一次跟你做生意。

这不是小概率事件。 这个行当的平均寿命，比大部分人想得短。

2. 稳：它不是”慢”，是”没有保证”

  • 高峰期 503
  • 偶尔 429，说请求太多
  • 回答到一半断流
  • 昨天还好好的模型，今天换了个版本
  • 上午能用，下午打不开

单看每一条都不致命。加起来就是一句话：你没法把它放进任何需要”稳定”的地方。

3. 质：它可能偷偷降了你的规格

  • 上下文被截断
  • 输出长度被限制
  • 图片能力被关掉
  • 思考过程被省略
  • 换成了便宜模型

这些都不会写在价目表上。

4. 隐私：它是你所有对话的必经之路

这一点最容易被忽略。

用官方 API，数据从你的电脑到官方的服务器，中间是加密的。

用中转站，数据先到它的服务器，再由它转发。它想不想看、看不看、存不存、存多久，你都不知道。

对企业来说，这一条基本是一票否决——尤其是涉及客户资料、合同、代码的时候。

5. 合规：合同、发票、数据出境

  • 没有服务合同，出事没人赔
  • 发票能不能开、开得对不对，另说
  • 数据出境有没有申报，另说
  • 采购流程过不过得了审计，另说

小团队可能不在乎。公司一定在乎。

七、拿到一个陌生的站，怎么用半小时判断

这一段是实操。你不需要懂技术，照着做就行。

第一步：看它敢不敢写清楚

  • 模型版本写不写全称？写”GPT-6 系列”这种含糊话的，绕道
  • 上下文长度写不写具体数字？
  • 有没有明说”不支持某某能力”？
  • 有没有写清楚数据怎么处理？

越是含糊其辞的，越有问题。 因为写清楚了，它就没法偷偷降级。

第二步：拿一段固定文本，对一下 token 数

这个办法，慧妈在第一篇里就用来数过 token。

同一句话，不同的模型数出来的块数不一样。人工智能时代来了！ 这一句，老一代分词器数出 18 块，中间那代数出 10 块，新的数出 5 块。

你发一段固定的、稍微长一点的中文，看它返回的 prompt_tokens 是多少，再除以字符数，算一个比值。

同一个模型，这个比值应该是稳定的。 如果你隔一个星期再测，比值突然变了——要么模型换了，要么它改了返回的数字。

（提醒一句：这个数在技术上是可以伪造的，所以它只能当参考，不能当证据。）

第三步：测长上下文

找一份八万字左右的东西，比如一部长篇小说，在中间塞一句莫名其妙的话：

第三部分的暗号是紫色苹果。

然后问它：暗号是什么？

  • 答出来了：上下文是真的
  • 答不出来，或者只说前面几段：被截断了

第四步：测多模态和工具

  • 传一张带字的截图，让它把字读出来
  • 让它严格输出一个 JSON
  • 如果支持 function calling，让它调一个

这三样，逆向站基本全军覆没。

第五步：小额试水，别一次充一年

先充最小额度，用一个星期。

一个星期足够暴露大部分问题：断流、限速、降级、跑路前兆。(其实，不存在完全靠谱的中转站，在使用中转站提供的模型时，最好是用多少充多少，随用随充，别太信任他们，一下子充个几百上千的)

八、几个你一定会好奇的问题

问：中转站能看到我和 AI 的聊天内容吗？

答：技术上完全可以。

你的请求必须经过它的服务器，它才能转发。既然经过了，它就能记下来。

至于它记不记、记多久、拿去干什么，没有任何机制能约束它——除非它自己写了承诺，而承诺这东西，跑路的时候一分不值。

所以有一条铁律：凡是你不愿意贴在公网上的东西，都别贴进对话框。 这句话上一篇也说过，在 API 这一层更要紧——因为这次连”官方”都不在中间了。

问：用中转站会不会违法？

答：我不打算在这儿给你下法律结论，只说三件实在的。

  1. 你买的东西，来源可能是盗刷或者套利，真出事的时候，你很难自证清白
  2. 你的数据经过了一个你不知道底细的主体
  3. 公司采购走这条路，审计那一关基本过不去

个人学习、试验，问题不大；商业用途、涉密内容，别碰。

问：官方为什么不封？

答：一直在封。

异常调用量、异常注册、异常支付，官方都有一套风控。所以这行的常态是”开一批、封一批、再开一批”。

你看到”这家站开了三年很稳”，要么它货源干净，要么它换壳换得勤。

问：为什么有的站能开发票？

答：注册个公司就能开。

发票证明的是”它是个合法经营的主体”，不证明”它有官方授权”。这两件事是两回事，很多人会混。

问：那我到底该不该用？

答：分三档说。

你的场景 建议
学习、玩、试新模型 可以用，充最小额度，别放隐私
个人小项目、非关键用途 可以用便宜的，但要有”随时换一家”的准备
商业产品、客户数据、公司采购 不建议，走官方或者云厂商

问：为什么同一家站，上午很顺，晚上很卡？

答：两个可能。

一是它的号池在晚上被用满了；二是上游官方在晚上限流。两种情况你都解决不了，只能等。

问：那”官方直连”是不是就一定好？

答：好，但你可能连不上。

支付、网络、实名，这三道坎是真实存在的。中转站解决的正是这三道坎。

所以准确的说法是：你是在用”便宜”换”确定性”，还是在用”确定性”换”便宜”。

想清楚这笔交换，你就不容易被九块九冲昏头。

九、三条底线

如果你看完还是想用，那就守住这三条。

第一条：小额。 一次充够一个月用的量就行，别囤。

第二条：脱敏。 客户名单、身份证号、合同、密钥、公司代码，一个字都别贴。

第三条：留后路。 你的代码里，把 base_url 写成一个配置项，别写死。哪天真要换，改一行就能走。

这三条没什么技术含量，但每一条都是有人用真金白银换来的。慧妈把它们放在最后，不是凑数——它们比前面所有原理都管用。

结语

好了，以上便是本期教学的所有内容了。

我们回到开头那笔账：$5.20 和 $0.52。

现在你应该能看出来了——这两个数字之间差的不是”效率”，是”有人把成本挪走了”。

挪到哪儿去了？三个地方：

  • 挪到了规模上：缓存、共享前缀、量大折扣。这一部分是正当的，也是它真正比你强的地方
  • 挪到了你的体验上：截断上下文、偷偷降级、限速、断流。你付得少，拿到的也少
  • 挪到了明天：免费号会被封，会员号会被限，充值的余额会跟着站点一起消失

所以”为什么这么便宜”这个问题，真正的答案是：

因为它卖给你的，不完全是同一个东西。

有的是”同一个东西，便宜一点”；有的是”缩水的东西，便宜很多”；还有的是”明天就没了的东西，便宜到离谱”。

而价签上，它们长得一模一样。

这也是我为什么花了一整节讲”怎么验”，而不是直接甩给你一个”推荐名单”——名单会过期，判断方法不会。

如果这篇只能留一句话给你，慧妈希望是这句：

如果你说不清它凭什么这么便宜，那这个便宜本身就是风险。
